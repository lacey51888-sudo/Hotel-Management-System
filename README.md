# Hotel Management System

## Introduction

A web-based hotel management system developed using PHP, MySQL, HTML, CSS and JavaScript.

## Features

- User registration and login
- Room search and booking
- Order management
- Customer review system
- Staff task management
- KPI and performance statistics

## Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript
